# Smart Moves and Junior Scores

The **Smart Moves** and **Junior** tabs work the same way.

1. Open the tab and tap **Select a game to input score**. Pick the game you are playing in class.

<img src={require("./img/tt-sm-pick.png").default} alt="Pick a game" width="380" />

2. Each student now shows that game with their current **level**. Tap **Input** next to a student. (Tap **▶ VIDEO** to watch the exercise.)

<img src={require("./img/tt-sm-list.png").default} alt="Input" width="380" />

3. The score form shows the level, the instruction and the video. Rate each item, then tap **Submit**. The score is saved to the student's game progress, the same as playing the level.

<img src={require("./img/tt-sm-input.png").default} alt="Score form" width="380" />

:::note
A game shows **Not started yet** (and no **Input** button) when it has not been started for that student. It has to be assigned and started first (Class or Student **Game config** in ACP).

<img src={require("./img/tt-jr-list.png").default} alt="Not started yet" width="380" />
:::

:::caution
In **Junior**, the grey **Skip** button submits the default score straight away. Use it only when you really mean to skip the level.
:::
