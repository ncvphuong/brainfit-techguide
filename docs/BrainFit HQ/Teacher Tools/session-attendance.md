# Attendance

1. Open the **Attendance** tab.
2. Under each student, tap **Present**, **Absent** or **Excused**. Tap **Reset** to clear it back to **Not Marked**.
3. **All Present** / **All Absent** at the top marks the whole session in one tap, then change the few who are different.

<img src={require("./img/tt-attendance.png").default} alt="Attendance" width="380" />

Each tap saves straight away; there is no separate Save button.
