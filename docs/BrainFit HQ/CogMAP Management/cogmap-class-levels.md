# Assign CogMAP V2 Levels and Questions to a Class
This feature is for SA, ML, MA, CA

**This page is out of date.** A class no longer keeps a CogMAP V2 setup, and the CogMAP V2 preset and question form on the class's **Game config** page has been removed. CogMAP V2 now uses only each student's own setup.

- To set up and start CogMAP for a whole class (or several classes of a centre) in one go, see [Start CogMAP for a Class or a Centre](./cogmap-start-class.md).
- To set up one student, see [Student CogMAP Setup and Activation](./cogmap-student-setup.md).

**Note:** the **CogMAP Questions** section on the class page is the old CogMAP V1.
